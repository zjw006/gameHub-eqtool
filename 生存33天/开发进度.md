# 《生存33天》复刻版 · 开发进度

> 参考对象：微信小游戏《生存33天》。本工程为玩法研究用的高保真复刻，目标是验证「搜→打→撤」核心循环与 33 天节奏设计。

## 技术栈

- **前端**：React 19 + TypeScript + Vite + Tailwind CSS 3.4
- **渲染**：Canvas 2D 自研引擎（requestAnimationFrame 主循环、DPR 适配、Y 排序伪 2.5D、径向渐变战争迷雾）
- **美术**：纯代码绘制的 Q 版二头身角色（参数化 Look：肤色/发型/帽子/武器/服装配色），零图片资源依赖
- **音频**：WebAudio 合成音效（射击/近战/拾取/警报/胜负等），无音频文件
- **持久化**：localStorage（`survive33_meta_v1`），纯前端无后端

## 已知限制

- **无后端**：存档仅在当前浏览器 localStorage，换设备/清缓存丢失
- **单地图**：原版中期会轮换街区/医院等地图，当前仅地铁站一张（事件靠雾色/刷怪区分天数体验）
- **数值为复刻推演值**：非原版真实数值，平衡性未经过完整 33 天流程验证
- **无联盟/公会、无付费点**：仅单机循环

## 下一步候选

1. **多地图轮换**：街区（白天户外）/ 医院（室内迷宫）按天数阶段轮换

3. **33 天全流程平衡性测试**：脚本自动跑通，校验战力成长曲线 vs 难度曲线
4. **英雄技能差异化**：当前英雄差异主要在数值和射程，可加被动技能（如尸王日增伤、浓雾视野免疫）
5. **后端存档**：接入云数据库 + 账号，支持跨设备
