# 《生存33天》复刻版 · 玩法说明

> 目标：带领幸存者小队在废墟中搜集物资、击退尸群，撑过 33 天，登上最后一天的撤离直升机。

---

## 一、核心循环

```
庇护所（建造 / 养成 / 布阵 / 抽卡）
        ↓ 出发探索
废土战斗（搜 → 打 → 撤）
        ↓ 结算
资源回写 · 天数 +1 → 回到庇护所
```

- **搜**：进入地图后完成「今日任务」（搜集罐头 / 清剿尸群 / 开金宝箱 / 击败尸王）
- **打**：丧尸自动索敌，小队自动战斗，你只负责走位
- **撤**：任务完成后前往地图右下角的撤离圈，站满进度条即可带走全部物资

## 二、战斗操作

| 操作 | 方式 |
|---|---|
| 移动 | 按住屏幕任意位置拖出虚拟摇杆；键盘 WASD / 方向键 |
| 战斗 | 全自动（无手动技能），坦克顶前、输出殿后，走位拉扯保护后排 |
| 雷达 | 右上角小地图：黄点=物资、红点=已惊动的敌人、绿圈=撤离点 |
| 边缘箭头 | 屏幕边缘的箭头指向当前任务目标（最近的罐头/宝箱/丧尸/尸王） |
| 幸存者 | 左下角按钮查看小队实时血量 |

**失败惩罚**：全队阵亡或倒计时归零 → 本局搜集的物资全部丢失，但天数不变，可以重新探索。

## 三、33 天节奏曲线

| 阶段 | 天数 | 名称 | 特点 |
|---|---|---|---|
| 前期 | 1-15 | 废墟拾荒 | 尸群零散，难度平缓，抓紧囤积 |
| 中期 | 16-25 | 危机四伏 | 疾行种出没，敌人增援 +6，难度陡增 |
| 后期 | 26-32 | 至暗时刻 | 重装种成群，增援 +12，血量 ×2.9 起 |
| 终局 | 33 | 最终撤离 | 双尸王拦路，5 分钟时限，击败后登机通关 |

### 每日事件（庇护所底部「今日预报卡」可见）

| 天 | 事件 | 效果 |
|---|---|---|
| 5 / 20 / 32 | 物资空投 | 地图 +4 罐头、+1 金宝箱 |
| 8 / 22 / 30 | 尸潮来袭 | 敌人海量增援，击杀奖励 +50%~80% |
| 12 | 浓雾弥漫 | 视野缩小 40%，散落物资 +2 |
| 15 / 25 | 尸王现身 | 额外一只尸王，击杀奖励翻倍 |
| 18 / 28 | 血月当空 | 雾变血红，丧尸攻击 +30%，奖励翻倍 |
| 33 | 最终撤离 | 双尸王 + 三倍奖励 |

### 每日任务轮换

- **搜集物资**：捡够 N 个罐头（前期 6 / 中期 7 / 后期 8）
- **清剿尸群**：击杀 N 只丧尸（前期 8 / 中期 12 / 后期 16）
- **开启金宝箱**：找到并开启站台金宝箱
- **击败尸王**（仅第 33 天）：击败 2 只尸王

通关后可选择 **继续坚守**（无尽模式，事件循环加剧）或 **重新挑战**（保留英雄和建筑，回到第 1 天）。

## 四、幸存者系统

- **品质**：精良（蓝）→ 史诗（紫）→ 传说（金）→ 神话（红），品质倍率 ×1 / 1.25 / 1.55 / 1.9
- **职业**：坦克（前排抗伤）/ 远程（步枪输出）/ 战士（近战）/ 辅助（治疗队友）
- **升级**：消耗物资 + 食物，最高 30 级
- **招募电台**：单抽 / 十连消耗招募券；60 抽必出神话；抽到重复英雄自动折算 +60 物资

## 五、布阵

- 6 格站位：**0-2 号位前排**（顶在行进方向），**3-5 号位后排**
- 坦克放前排，远程和辅助放后排
- 布阵直接决定战斗中的站位偏移

## 六、庇护所建造

9 块地对应 9 种建筑，按解锁链顺序建造，最高 5 级：

| 顺序 | 建筑 | 效果 |
|---|---|---|
| 1 | 工作台 | 木材产出 +3/分钟/级 |
| 2 | 储物箱 | 探索物资需求 -1 |
| 3 | 围栏路障 | 全队生命 +8%/级 |
| 4 | 床铺 | 脱战回复速度 ×2/级 |
| 5 | 农田 | 食物产出 +3/分钟/级 |
| 6 | 雨水过滤器 | 净水产出 +3/分钟/级 |
| 7 | 医疗站 | 战斗中每秒回 2 血/级 |
| 8 | 防御塔 | 全队攻击 +6%/级 |
| 9 | 高级锻造台 | 全队攻击 +8%/级 · 物资产出 +2/分钟/级 |

- 离线也会按分钟产出（上限 8 小时），回庇护所自动结算
- 每级建筑 +60 战力

## 七、资源一览

| 资源 | 用途 | 来源 |
|---|---|---|
| 木材 | 建造/升级 | 探索结算、工作台产出 |
| 石料 | 建造/升级 | 探索结算 |
| 食物 | 英雄升级 | 探索结算、农田产出 |
| 净水 | 储备 | 探索结算、过滤器产出 |
| 物资 | 英雄升级 | 探索搜集、重复抽卡折算、锻造台产出 |
| 招募券 | 抽卡 | 每日探索 +1，开金宝箱 +2 |
| 钻石 | 储备货币 | 开金宝箱 +20 |

## 八、新手建议

1. 前几天优先建 **工作台 + 储物箱**，离线木材 + 任务减负收益最大
2. 事件日（尸潮/血月）奖励高但危险，战力不够就在基地多囤一天
3. 空投日多绕路捡金宝箱：+2 物资、+2 招募券、+20 钻
4. 第 15 / 25 / 33 天的尸王日之前，记得把主力升几级、检查布阵
5. 战斗中别站桩——拉着尸群绕圈，让后排远程白打输出
